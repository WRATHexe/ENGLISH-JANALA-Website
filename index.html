Frequently Asked Questions

var is function-scoped and allows re-declaration. let is block-scoped and can be reassigned. const is block-scoped and cannot be reassigned. Use let for variables that change and const for constants.
map() returns a new transformed array. forEach() executes a function but doesn’t return anything. filter() creates a new array with elements that meet a condition.
Arrow functions have a shorter syntax, inherit this, and don’t have arguments. Regular functions have their own this, support arguments, and can be used as constructors.
Promises handle asynchronous operations with states: pending, fulfilled, or rejected. Use .then() for success and .catch() for errors.
Closures allow a function to retain access to variables from its outer scope, even after the outer function has finished executing.
